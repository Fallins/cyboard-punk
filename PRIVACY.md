# Privacy

CYBOARD is designed to work locally on the user's Mac.

## Data CYBOARD may read
- local provider installation/login state;
- provider quota/reset information;
- bounded normalized quota history generated by CYBOARD;
- local process metadata needed to identify active coding-agent sessions;
- local session metadata for usage/project attribution when that feature is enabled and implemented.

## Data CYBOARD does not collect
CYBOARD does not operate a server, does not upload usage history to the project owner, and does not include third-party analytics or advertising SDKs. Provider network calls go only to the provider endpoints required to retrieve account quota/usage state.

## Credentials
Provider credentials remain local and are used only in the native process. They are not sent to the UI, stored in CYBOARD history, or exported.

## Future features
Any optional cloud sync, telemetry, voice service, or remote monitoring feature must be opt-in and documented here before release.
