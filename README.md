# CYBOARD

> Cyberpunk command center for AI coding agents.

CYBOARD is a local-first macOS menu bar app and dashboard for monitoring AI coding-agent quota, reset windows, activity, usage history, burn rate, and health across Codex, Claude Code, Cursor, and future providers.

The project is built around a provider-adapter architecture, strict privacy boundaries, automated tests, and explicit performance budgets. Product planning, implementation rules, brand assets, and operator-character specifications live in `docs/`.

## Current status

Project bootstrap in progress. Phase 1 delivers the useful monitoring core; Phase 2 adds the holographic 3D CYBOARD Operator without compromising idle CPU/GPU use.
